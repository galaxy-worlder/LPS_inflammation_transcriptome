\# LPS–Sepsis Transcriptome Concordance Analysis



\## 项目简介



本项目基于公开转录组数据，分析 LPS 刺激诱导的人巨噬细胞转录组响应，并进一步评估该响应模式与临床急性脓毒症血液表达谱之间的一致性。



LPS 刺激巨噬细胞是研究感染相关炎症反应的经典体外模型，但临床脓毒症是一种复杂的全身性炎症和免疫失衡状态，受到病原体类型、感染部位、疾病阶段、治疗干预以及外周血免疫细胞组成变化等多种因素影响。因此，本项目的核心问题是：



体外 LPS 刺激人巨噬细胞模型能在多大程度上反映临床急性脓毒症中的转录组改变？



本项目整合了三个公开数据集：



\* GSE193336：LPS 刺激人巨噬细胞 RNA-seq 数据，用于发现 LPS 响应基因

\* GSE5504：人单核细胞 LPS 刺激时间序列数据，用于验证核心 LPS 响应基因的动态表达模式

\* GSE154918：临床外周血 RNA-seq 数据，用于比较 LPS 响应与急性脓毒症血液转录组改变之间的一致性



\## 研究设计



本项目主要包括三个分析阶段：



1\. LPS 响应基因识别

&#x20;  使用 GSE193336 比较未刺激组与 LPS 刺激组的人巨噬细胞表达差异，识别显著 LPS 响应基因。



2\. 功能富集与时间序列验证

&#x20;  对 LPS 响应基因进行 GO、KEGG 和 GSEA 分析，并使用 GSE5504 验证代表性炎症和免疫调控基因在 LPS 刺激后的动态表达模式。



3\. LPS 响应与急性脓毒症表达谱一致性分析

&#x20;  使用 GSE154918 分析急性脓毒症患者与健康对照之间的差异表达基因，并与 GSE193336 中的 LPS 响应基因进行重叠分析、方向一致性分析和 log2FC 相关性分析。



\## 主要结果概述



本项目的主要发现包括：



\* 在 GSE193336 中，LPS 刺激诱导人巨噬细胞发生广泛转录组改变，共鉴定到 4,083 个显著 LPS 响应基因。

\* 功能富集分析显示，LPS 响应主要表现为炎症反应、细胞因子信号、趋化因子信号、Toll-like receptor、NOD-like receptor 和 JAK-STAT 等固有免疫相关通路的激活。

\* GSE5504 时间序列数据支持多个核心炎症基因在 LPS 刺激后呈现动态诱导模式。

\* 与 GSE154918 急性脓毒症血液转录组比较发现，LPS 响应基因与急性脓毒症相关差异基因之间存在显著重叠。

\* 共有 1,496 个基因在 LPS 刺激和急性脓毒症中均显著改变，其中 906 个基因呈一致变化方向。

\* 虽然两种状态下整体 log2FC 相关性较弱，但体外 LPS 刺激仍能捕捉临床急性脓毒症中部分炎症、固有免疫和髓系细胞相关转录特征。



总体而言，本项目支持以下结论：



LPS 刺激人巨噬细胞可以作为理解急性炎症转录程序的简化模型，但不能完全代表临床脓毒症的复杂分子状态。

\## 推荐脚本顺序



建议按照以下顺序运行分析脚本：



1\. scripts/01\_GSE193336\_DE\_analysis.R

&#x20;  对 GSE193336 进行预处理、标准化、差异表达分析，并生成 PCA、MA 图、火山图和热图。



2\. scripts/02\_enrichment\_analysis.R

&#x20;  基于 GSE193336 的差异表达结果进行 GO、KEGG 和 GSEA 功能富集分析。



3\. scripts/03\_GSE5504\_time\_series\_validation.R

&#x20;  使用 GSE5504 时间序列数据验证代表性 LPS 响应基因的动态表达模式。



4\. scripts/04\_GSE154918\_sepsis\_DE\_analysis.R

&#x20;  对 GSE154918 中健康对照与急性脓毒症样本进行差异表达分析。



5\. scripts/05\_LPS\_sepsis\_concordance\_analysis.R

&#x20;  比较 LPS 响应基因与急性脓毒症相关差异基因，进行重叠分析、方向一致性分析、Spearman 相关分析和候选基因筛选。



\## 数据来源



本项目使用的所有数据均来自 GEO 公共数据库。



\* GSE193336

&#x20; 用于分析 LPS 刺激后人巨噬细胞的转录组改变。



\* GSE5504

&#x20; 用于分析人单核细胞在 LPS 刺激后不同时间点的动态表达变化。



\* GSE154918

&#x20; 用于分析健康对照、感染、脓毒症和脓毒性休克患者外周血 RNA-seq 表达谱。



原始数据可通过 GEO 数据库下载。本仓库不直接提供原始测序数据。



\## 主要分析方法



本项目主要使用 R 和 Bioconductor 完成数据分析。



主要方法包括：



\* GEO 数据读取与样本注释整理

\* 表达矩阵预处理与基因 ID 注释

\* edgeR 和 limma-voom 差异表达分析

\* limma 差异表达分析

\* PCA 样本整体表达模式分析

\* MA 图、火山图和热图可视化

\* GO Biological Process 富集分析

\* KEGG 通路富集分析

\* GSEA 基因集富集分析

\* Fisher 精确检验评估基因重叠显著性

\* Spearman 相关分析评估 log2FC 整体一致性

\* LPS–sepsis 方向一致候选基因筛选

\## 代表性候选基因



在 LPS 刺激和急性脓毒症中呈一致变化方向的候选基因包括：



\* IL1B

\* SOCS3

\* TNFAIP6

\* AIM2

\* IFITM1

\* IFI27

\* S100A12

\* JAK3



这些基因主要与炎症反应、细胞因子信号、干扰素相关反应和髓系免疫细胞功能有关。需要注意的是，这些候选基因仅作为公共转录组整合分析得到的后续验证线索，不能直接解释为脓毒症的因果驱动基因或治疗靶点。



\## 研究局限性



本项目基于公开转录组数据进行整合分析，仍存在以下局限：



1\. 未包含本研究团队独立采集的实验样本。

2\. 不同数据集之间存在细胞类型、实验平台、样本来源和刺激时间差异。

3\. GSE154918 为外周血转录组数据，表达变化可能受到免疫细胞组成变化影响。

4\. 候选基因排序属于探索性分析，不能直接用于临床诊断、预后预测或治疗决策。

5\. 本项目主要关注转录组水平，未整合蛋白质组、代谢组或临床结局数据。



\## 数据可获得性



本研究使用的数据均为公开可获得数据，来源于 GEO 数据库。由于本研究未采集新的患者样本，且所有数据均为公开数据库中的去标识化数据，因此不涉及新的伦理审批。
